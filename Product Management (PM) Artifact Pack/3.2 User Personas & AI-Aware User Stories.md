**3.2 User Personas & AI-Aware User Stories**

In an AI-powered product, user personas and stories cannot assume deterministic software behavior; they must explicitly account for **model uncertainty, trust calibration, and the cost of false positives/negatives:**

|Persona & Role|AI-Aware User Story (As a... I want... So that...)|Acceptance Criteria & Uncertainty / Error-Cost Handling|
|---|---|---|
|Priya Nair — Senior MRD Coding Officer (8 yrs exp; processes 30 charts/day)|As a Coding Officer, I want Chart Ready AI to suggest top ICD-10 diagnosis codes with confidence scores and highlighted source sentences from the surgical discharge summary, so that I can verify and lock codes rapidly without reading 10 pages line-by-line.|• Displays top 1–3 ICD-10 candidates from the vetted 50-code surgical dictionary.<br>• Clicking a code highlights the exact supporting phrase in the PDF/text viewer.<br>• Low-confidence (<65%) suggestions display an amber 'Manual Lookup Required' warning and cannot be one-click accepted without opening the source span.|
|Ramesh Kumar — MRD Deficiency Officer (4 yrs exp; audits 60+ files/day)|As a Deficiency Officer, I want the system to flag missing signatures, absent discharge conditions, or insufficient follow-up advice immediately upon chart ingestion, so that I can dispatch a structured sign-off request to the resident doctor before shift handover.|• Evaluates all 5 mandatory NABH fields within 15 seconds of file upload.<br>• Distinguishes between 'Blank Field' and 'Clinically Insufficient Text' (e.g., single word 'OK').<br>• Physician must explicitly authenticate and sign off; AI never auto-completes clinical text.|
|Dr. Kavitha Menon — Head of MRD & HIM Manager (15 yrs exp; owns NABH & TPA KPIs)|As the MRD Head, I want a live triage queue that prioritizes high-value TPA claims and low-confidence AI charts while logging every coder override reason, so that I can prevent billing SLA breaches and audit systematic model drift.|• Triage queue sorts by Priority Score (Claim Value × Audit Risk × Uncertainty).<br>• Dashboard tracks Coder Acceptance Rate vs. Manual Audit accuracy weekly.<br>• Alerts manager if coder acceptance exceeds 95% (automation complacency flag) or drops below 60% (model degradation flag).|
