**2.5 Build vs. Buy vs. Partner or API Decision**

A central strategic decision for an AI Product Manager is determining where proprietary value resides across the AI stack **(Platform vs. Feature / Workflow Logic).** Following the approved Milestone 1 strategy, Team 056 recommends an **API-First + Proprietary Workflow Orchestration** approach rather than building a clinical NLP model from scratch or buying a rigid off-the-shelf US-centric Computer-Assisted Coding (CAC) suite:

|Strategic Option|Pros & Capabilities|Cons & Operational Barriers|Verdict for Chart Ready AI|
|---|---|---|---|
|Option 1: Build Custom Clinical NLP Model from Scratch|Full control over model weights; zero ongoing per-token API fees at massive scale|Requires 50,000+ gold-standard annotated Indian discharge charts, scarce ML engineering talent, 12–18 months R&D, and high GPU capex|REJECTED for MVP/Pilot. Premature capital commitment before proving workflow fit|
|Option 2: Buy Off-the-Shelf Global Enterprise CAC Suite (e.g., 3M / Solventum, Optum)|Mature coding dictionaries and established US HIPAA compliance|Prohibitively expensive enterprise licensing; calibrated for US DRG/CPT workflows rather than Indian NABH checklists, TPA rules, and scanned hybrid charts|REJECTED. High cost and poor localization for Indian MRD deficiency workflows|
|Option 3: API-First Enterprise LLM inside Secure VPC + Custom HITL Workflow (Recommended)|Deploys in weeks; leverages state-of-the-art clinical language comprehension via zero-retention VPC API; focuses engineering on checklist rules, RAG grounding, and coder UX|Incurs variable per-chart API token cost (~₹2.5–₹4.5/chart); requires strict PHI de-identification and prompt governance|SELECTED. Maximizes learning velocity; revisit fine-tuned open-weight models (Llama-3-Med) only after pilot scale|
