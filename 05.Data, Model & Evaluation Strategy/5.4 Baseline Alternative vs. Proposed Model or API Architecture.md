**5.4 Baseline Alternative vs. Proposed Model or API Architecture**

**Baseline Comparison:** Before deploying LLM inference, we benchmark against two non-AI baselines: (1) 
**Baseline A (Manual As-Is):** Unassisted human coding and manual completeness flipping (TAT: 54 hrs; Coding time: 24 mins; Denial rate: 14.5%); and (2) **Baseline B (Deterministic Regex + TF-IDF Keyword Matcher):** A rule script checking for non-empty section headers and matching exact ICD-10 title strings. In preliminary testing on surgical notes, Baseline B achieves <45% recall because surgeons write clinical narratives ('lap chole for symptomatic gallstones with bile duct exploration') rather than verbatim WHO classification titles.
**Proposed Architecture (API-First RAG Pipeline inside Hospital VPC):** As depicted in Figure 3, Chart Ready AI uses a modular, privacy-preserving pipeline: (1) **OCR & Layout Parser** extracts structured sections; (2) **Local PHI De-Identification Gate** strips 18 HIPAA/DPDP personal identifiers locally; (3) **Hybrid RAG + Enterprise LLM API** (e.g., Azure OpenAI GPT-4o / Claude 3.5 Sonnet deployed on a regional India cloud endpoint with contractual zero-data-retention) retrieves candidate codes from a local **FAISS/Chroma Vector Index** of the 50 surgical ICD-10 codes and outputs structured JSON (`pydantic` schema enforcement); and (4) **Confidence Router & HITL Gate** governs human verification before re-identification and billing export.
