**4.5 Uncertainty Handling & Fallback Behavior Matrix**

|Confidence / System State|Threshold Criteria|UI Visual Treatment|System Behavior & Mandatory Human Action|
|---|---|---|---|
|High Confidence|Calibrated Score >= 85% AND all 5 completeness fields present|Teal badge ('High Confidence — 94%'); green highlight on source clinical span|Eligible for single-click \[Accept\] by standard Coding Officer; still requires explicit human click (never auto-submitted).|
|Medium Confidence|Calibrated Score 65% – 84% OR minor terminology ambiguity|Amber badge ('Verify Specificity — 74%'); side-by-side sibling code comparison shown|Coder must click the highlighted text span before \[Accept\] unlocks, or use \[Edit\] to select the exact 4th/5th character code.|
|Low Confidence / High Risk|Score < 65%, Claim Value > ₹1,00,000, or Known Audit-Sensitive Category|Coral alert banner ('Escalated to Senior Review Track — Low Confidence / High Claim')|Automatically routed to Senior Coding Officer queue; one-click accept disabled; requires manual code verification and sign-off.|
|System Failure / OOD Fallback|OCR Confidence < 75%, Diagnosis outside Top-50 MVP scope, or API timeout > 12s|Neutral Slate banner ('AI Pre-Check Bypassed — Standard Manual Review Mode')|Graceful degradation: opens chart in standard manual coding interface with zero delay to MRD workflow; logs event for engineering.|
