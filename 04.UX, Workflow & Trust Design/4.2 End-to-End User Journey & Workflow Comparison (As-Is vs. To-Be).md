**4.2 End-to-End User Journey & Workflow Comparison (As-Is vs. To-Be)**

Figure 1 illustrates the structural transformation from the current fragmented manual workflow to the AI-assisted, risk-triaged workflow in Chart Ready AI. Rather than treating every file identically in a slow paper queue, the To-Be workflow executes automated pre-screening within seconds of discharge summary generation and routes each file along a calibrated human review track:

<img width="960" height="551" alt="image" src="https://github.com/user-attachments/assets/7bd89680-61a3-4eb8-8203-b9497198e05f" />Figure 1: End-to-End MRD Discharge Record Workflow comparing the current manual FIFO process (top) with Chart Ready AI's triaged HITL workflow (bottom).

**Step-by-Step Interactive User Journey:**

**1. Ingestion & Instant Triage (0–15 seconds):** When a patient is discharged from General Surgery, the draft or signed discharge summary PDF/text is ingested into the VPC. Chart Ready AI strips direct patient identifiers, evaluates the 5 mandatory NABH fields, generates candidate ICD-10 codes, and assigns the chart to one of three tracks: High-Risk / High-Value Priority Track, Deficiency Chasing Track, or Standard Coding Queue.

**2. Deficiency Resolution Loop (Secondary Persona):** If a required element is missing (e.g., missing Attending Surgeon signature or blank follow-up medication advice), the Deficiency Officer reviews the pre-populated flag and clicks 'Dispatch Physician Alert'. Crucially, **the AI never fabricates or signs clinical content;** the responsible clinician receives a deep link, appends the missing clinical note or digital signature, and re-releases the chart.

**3. Evidence-Linked Coding Review (Primary Persona):** The Coding Officer opens the next prioritized chart in the 3-pane workspace (Figure 4). The left pane shows queue priority; the center pane displays the original clinical summary with color-coded evidence spans; the right pane lists recommended ICD-10 codes with confidence badges.

**4. Mandatory HITL Action & Reason Capture:** For each recommended code, the coder clicks **[Accept], [Edit]** (opening an inline ICD-10 search bar), or **[Reject]** (selecting a mandatory reason code such as 'Rule-out / unconfirmed condition', 'Specificity mismatch', or 'Hallucinated span'). Once all completeness checks and codes are resolved, the coder clicks **[Confirm & Export to Billing].**
